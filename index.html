useCourierFile uploads with real progress

A headless React hook with XHR progress tracking, retries, cancellation, and chunked uploads for large files.

Get Started
View on GitHub

  • Real upload progress

    Built on XMLHttpRequest instead of fetch, so you get real 0-100% progress events fetch can't give you.

  • Retries and cancellation

    Retry a failed upload or cancel one in flight, with lifecycle callbacks to hook in your own side effects.

  • Chunked uploads for large files

    Files too big for a single request are split into sequential chunks, each retried independently on failure.

  • Headless and typed

    No UI, no styling opinions — bring your own components. Fully typed API with generics for your response shape.
